### 0.1 状态标记约定

本文所有关键结论均带状态标记，避免把推测伪装成事实：

- **【已确认】**：来自用户明确表述、既有权威文档或已验证的系统行为。
- **【假设】**：为补齐文档结构所做的合理归纳，尚未获得人类确认。
- **【待确认】**：信息缺失或存在多种合理解释，需人类决策。
- **【冲突】**：不同来源的表述不一致，已并列保留，不得静默覆盖。

## 1. 背景与目标

### 1.1 背景

南京工业职业技术大学面向长三角软件和信息技术服务业，需要以真实产业数据支撑专业建设与人才培养决策。现有工作依赖分散的招聘信息、人工统计与经验判断，存在数据来源不可追溯、技能需求变化发现滞后、课程更新缺少证据链、年度专业调整缺少统一评审载体等问题。

### 1.2 业务目标

| 编号 | 目标 | 状态 |
|---|---|---|
| G-01 | 建立可追溯的长三角软件业岗位样本库，支撑岗位、技能、薪资、区域的持续观测 | 【已确认】 |
| G-02 | 用 AI 从岗位文本中稳定抽取技能、工具、工程能力标签，降低人工标注成本 | 【已确认】 |
| G-03 | 按区域与时间输出未来人才需求趋势，为专业方向与招生规模提供依据 | 【已确认】 |
| G-04 | 建设与产业需求对齐的课程、知识技能点与项目案例资源库 | 【已确认】 |
| G-05 | 形成“数据分析 → 调整建议 → 评审采纳 → 培养方案修订”的年度专业动态调整闭环 | 【已确认】 |
| G-06 | 通过角色权限与操作审计满足校内数据安全与责任可追溯要求 | 【已确认】 |

### 1.3 成功判据

- 核心业务场景均具备可复核的验收标准（见第 7 章），关键指标包括：5000 条内导入 ≤10 秒、抽取人工抽检准确率 ≥85%、预测输出未来 3 个月趋势、年度调整建议覆盖三类且不少于 4 项。
- 任一统计数字均可说明来源与口径，不存在写死的演示数据。

## 6. 核心场景与功能需求

### SCN-01 登录与会话

- **目标：** 用户以校内账号登录，系统识别身份与角色，并按角色控制可访问功能。
- **触发条件：** 用户访问系统或会话失效后重新访问。
- **关键流程：** 输入账号密码 → 校验账号状态与密码 → 返回身份与角色 → 按角色加载导航与页面。
- **业务规则：** 禁用账号不得登录；未登录不得访问受保护页面；角色不匹配时拒绝访问。
- **异常场景：** 密码错误、账号不存在、账号被禁用、令牌过期。
- **需求：**
  - **REQ-01** 支持账号密码登录，并返回用户身份与角色集合。【已确认】
  - **REQ-02** 未登录访问受保护资源应被拒绝，越权访问应返回无权限。【已确认】

### SCN-02 岗位样本导入与数据质量

- **目标：** 将 Excel/CSV 岗位样本可靠导入，并给出可复核的成功/失败报告。
- **触发条件：** 数据分析员或教师在数据导入页上传文件。
- **关键流程：** 上传文件 → 生成导入任务 → 异步解析清洗 → 去重覆盖入库 → 更新抽取状态 → 返回进度与失败明细。
- **业务规则：** 单批次 5000 条内导入 ≤10 秒；唯一键重复时覆盖更新；失败行必须给出原因，成功行不受影响。
- **异常场景：** 文件格式不支持、空文件、编码错误、必填字段缺失、批次超限、异步处理失败。
- **需求：**
  - **REQ-03** 支持 Excel/CSV 上传并异步导入，返回可查询的任务标识。【已确认】
  - **REQ-04** 导入任务需提供总数、成功数、失败数与失败明细。【已确认】
  - **REQ-05** 按岗位唯一键去重并覆盖更新，重复导入不得产生重复岗位。【已确认】
  - **REQ-06** 支持导入任务历史查询与抽取进度查询。【已确认】

### SCN-03 数据溯源与质量管理

- **目标：** 任何岗位样本都能回答“数据从哪来、何时采集”，并能汇总数据质量问题。
- **触发条件：** 用户在岗位详情查看溯源，或进入质量报告。
- **关键流程：** 打开岗位详情 → 查看来源渠道/原始链接/采集时间 → 查看质量报告与异常问题。
- **业务规则：** 溯源信息缺失的样本不得标记为可用；质量报告口径与导入任务结果一致。
- **异常场景：** 样本不存在、溯源记录缺失。
- **需求：**
  - **REQ-07** 提供岗位样本溯源查询（来源渠道、原始链接、采集时间）。【已确认】
  - **REQ-08** 提供数据质量报告与问题清单。【已确认】

### SCN-04 定时采集任务

- **目标：** 通过配置化任务周期性获取新数据，减少人工导入。
- **触发条件：** 管理员/数据分析员创建、启停或手动执行采集任务。
- **关键流程：** 配置来源与周期 → 到期自动执行或手动执行 → 复用导入链路 → 记录执行结果。
- **业务规则：** 周期表达式非法不得保存或应自动停用；重复文件按唯一键增量覆盖；任务需记录最近执行时间与结果。
- **异常场景：** 来源不可达、文件损坏、周期表达式非法、执行超时。
- **需求：**
  - **REQ-09** 支持采集任务的创建、修改、查询、删除与启停。【已确认】
  - **REQ-10** 支持按周期自动执行与手动立即执行，并记录最近执行状态与说明。【已确认】
  - **REQ-11** 非法周期表达式应被拒绝或使任务停用，不得静默执行。【已确认】

### SCN-05 岗位与技能分析

- **目标：** 支持按区域、技能、时间与关键字洞察岗位需求与技能热度。
- **触发条件：** 用户进入岗位与技能分析页或看板进行筛选。
- **关键流程：** 选择筛选条件 → 查询岗位列表与统计 → 查看技能热度、薪资/区域分布与相似岗位。
- **业务规则：** 筛选结果与统计口径一致；分页与排序稳定；相似岗位推荐排除自身。
- **异常场景：** 无匹配结果、筛选参数非法、检索服务不可用。
- **需求：**
  - **REQ-12** 支持岗位样本多维检索与分页查询。【已确认】
  - **REQ-13** 提供技能热度排行。【已确认】
  - **REQ-14** 提供薪资分布、区域分布与月度趋势统计。【已确认】
  - **REQ-15** 提供相似岗位推荐并排除当前岗位。【已确认】

### SCN-06 自然语言语义检索

- **目标：** 用户用自然语言描述需求，系统按语义相似度返回岗位。
- **触发条件：** 用户在分析页输入自然语言描述并发起检索。
- **关键流程：** 输入描述 → 可选区域筛选 → 向量相似度排序 → 返回命中岗位与总数。
- **业务规则：** 语义检索结果不得绕过权限与数据范围；索引与事实数据不一致时应可重建。
- **异常场景：** 查询为空、向量服务不可用、索引为空。
- **需求：**
  - **REQ-16** 支持自然语言语义检索，并可叠加区域筛选。【已确认】

### SCN-07 AI 岗位文本抽取

- **目标：** 将岗位描述转换为技能、工具、工程能力三类结构化标签。
- **触发条件：** 用户提交单条抽取，或批量抽取任务执行。
- **关键流程：** 读取岗位文本 → 调用当前模型 → 解析三类标签 → 记录模型与结果 → 回写抽取状态。
- **业务规则：** 三类标签结构必须完整；人工抽检准确率 ≥85%；大模型不可用时回退本地规则词典保证基础抽取可用；回退仍失败必须显式报错。
- **异常场景：** 模型超时/限流/鉴权失败、返回格式非法、文本为空。
- **需求：**
  - **REQ-17** 支持单条岗位文本抽取并返回三类标签。【已确认】
  - **REQ-18** 支持批量抽取进度查询。【已确认】
  - **REQ-19** 抽取结果需记录实际使用的模型名称，并在模型不可用时按规则回退或显式失败。【已确认】

### SCN-08 人才需求预测

- **目标：** 按区域输出未来 3 个月的岗位需求趋势。
- **触发条件：** 用户选择区域和预测月数发起预测。
- **关键流程：** 读取历史统计 → 运行预测 → 输出逐月需求值 → 展示历史与预测对比。
- **业务规则：** 预测需基于真实历史数据；区域无数据时不得编造；预测结果需标注模型与生成时间。
- **异常场景：** 历史数据不足、区域不支持、预测服务不可用。
- **需求：**
  - **REQ-20** 支持按区域输出未来 3 个月需求预测。【已确认】
  - **REQ-21** 支持查询历史预测结果与可选区域列表。【已确认】

### SCN-09 数据看板

- **目标：** 在一屏内呈现岗位总量、趋势、薪资、区域与技能热点。

- **关键流程：** 加载 KPI 与图表 → 支持区域/时间筛选 → 展示岗位热度、薪资分布、技能词云、区域地图与排行。
- **业务规则：** 看板数字与事实库一致；缓存只加速、不一致时可失效重算。
- **异常场景：** 统计数据为空、缓存不可用。
- **需求：**
  - **REQ-22** 提供 KPI、趋势、薪资分布、技能词云、区域地图与排行展示。【已确认】
  - **REQ-23** 看板统计需在数据变更后可失效重算，保证最终一致。【已确认】

### SCN-10 课程、知识技能点与项目案例

- **目标：** 建设与产业需求对齐的课程资源库，并支持资源间关联。
- **触发条件：** 用户浏览课程库，或专业负责人/系统管理员维护资源。

- **业务规则：** 课程编码唯一；课程维护仅限专业负责人/系统管理员；技能点与案例的增删改同样受角色限制。
- **异常场景：** 课程不存在、编码重复、绑定不存在的技能点、越权修改。

  - **REQ-24** 提供课程库查询与课程详情（含技能点与关联案例）。【已确认】
  - **REQ-25** 支持课程新增、修改与删除（限专业负责人/系统管理员）。【已确认】
  - **REQ-26** 支持知识技能点维护及课程-技能点绑定。【已确认】
  - **REQ-27** 支持项目案例维护及与课程的关联。【已确认】

### SCN-11 专业调整建议审批工作流

- **目标：** 教师提交课程/专业调整提案，专业负责人审批并全程可追溯。

- **业务规则：** 仅教师/专业负责人可提交；仅专业负责人可审批；终态不可重复审批；全过程写审计。

  - **REQ-29** 支持专业负责人审批通过/驳回，且终态不可再次审批。【已确认】
  - **REQ-30** 支持建议分页、详情与 Word/PDF 导出。【已确认】

### SCN-12 年度专业动态调整建议

- **目标：** 依据年度岗位与技能数据生成分类调整建议，支撑院内评审与培养方案修订。
- **触发条件：** 用户进入“专业调整建议”页面，或专业负责人/系统管理员采纳建议。

- **业务规则：** 三类建议数量规则为方向 2 条、课程 4 条、技能新点 3 条（数据不足时按可得条目生成）；优先级按样本占比阈值划分；建议编号按年度与分类唯一；重新生成保留已采纳状态；采纳需角色校验且不可重复；后两阶段评审仅展示真实状态，不得虚构。
- **异常场景：** 数据服务不可用、统计数据为空、重复采纳、越权采纳、建议不存在。
- **需求：**
  - **REQ-31** 基于真实岗位与技能数据生成并展示年度调整建议。【已确认】
  - **REQ-32** 支持专业负责人/系统管理员采纳建议，重复采纳被拒绝。【已确认】
  - **REQ-33** 展示评审周期、四阶段评审进度与数据依据，进度仅反映真实状态。【已确认】
  - **REQ-34** 数据依赖不可用时显式失败，不生成建议。【已确认】

### SCN-13 年度分析报告导出

- **目标：** 输出可用于汇报与归档的年度分析报告。
- **触发条件：** 用户选择年度与格式发起同步或异步导出。
- **关键流程：** 选择格式 → 生成报告 → 同步直接下载或异步轮询进度后下载。

- **异常场景：** 格式不支持、生成失败、任务未完成、文件丢失。
- **需求：**
  - **REQ-35** 支持年度报告 Word/PDF/Excel 同步导出。【已确认】
  - **REQ-36** 支持异步报告任务创建、进度查询与完成后下载。【已确认】

### SCN-14 大模型接入配置

- **目标：** 由系统管理员维护可用大模型，并在同一时刻仅启用一个当前模型。
- **触发条件：** 系统管理员进入“AI 大模型配置”页签进行维护或切换。
- **关键流程：** 查看模型列表 → 新增/编辑/删除/启用 → 设为当前 → 抽取能力使用当前模型并记录调用。
- **业务规则：** API Key 不得回传明文；编辑时留空表示不修改；当前模型不可删除/停用；同一时刻唯一当前模型。
- **异常场景：** 删除当前模型、停用当前模型、模型标识重复、鉴权失败。
- **需求：**
  - **REQ-37** 提供模型列表与用量统计，API Key 仅返回“已配置”状态。【已确认】
  - **REQ-38** 支持模型新增、编辑、删除、启用与设为当前。【已确认】
  - **REQ-39** 保证当前模型唯一，并保护当前模型不被删除/停用。【已确认】
  - **REQ-40** 抽取调用必须使用当前模型并记录模型名与调用结果。【已确认】

### SCN-15 用户、角色与审计

- **目标：** 管理校内账号与角色，并对关键操作形成只读审计链。

- **业务规则：** 用户与角色管理仅限系统管理员；审计查询限系统管理员/审计员/安全管理员；审计记录不可修改。

- **需求：**
  - **REQ-41** 支持用户查询、创建、启停与角色分配（限系统管理员）。【已确认】
  - **REQ-42** 支持审计日志分页查询（限系统管理员/审计员/安全管理员）。【已确认】
  - **REQ-43** 关键写操作需写入审计日志。【假设】

### SCN-16 导航与页面访问

- **目标：** 让不同角色以最少步骤到达其职责范围内的页面。
- **触发条件：** 用户登录后浏览系统。
- **关键流程：** 按角色渲染分组导航 → 访问页面 → 越权页面跳转无权限页。
- **业务规则：** 导航可见性不替代服务端权限；课程页支持直达调整建议页签的深链。
- **异常场景：** 直接输入越权地址、会话过期。
- **需求：**
  - **REQ-44** 提供按角色分组导航、页面标题与越权拦截。【已确认】

## 7. 验收标准 (Acceptance Criteria)

> 说明：以下标准聚焦业务行为与状态一致性，不描述界面细节。每条均需在实际验收中提供可复核证据。

### 7.1 身份与权限

**AC-AUTH-01（Happy）**
- **Given** 一个启用状态的校内账号
- **When** 使用正确账号密码登录
- **Then** 返回有效会话凭证、用户身份与角色集合，且可访问其角色允许的页面。

**AC-AUTH-02（Sad）**
- **Given** 未登录用户或角色不匹配的用户
- **When** 访问受保护资源或越权操作
- **Then** 未登录请求被拒绝（401），越权请求被拒绝（403），且不产生任何业务数据变更。

**AC-BIZ-02（角色隔离）**
- **Given** 教师、数据分析员、审计员、系统管理员四类账号
- **When** 分别访问用户管理、审计日志与业务审批功能
- **Then** 仅系统管理员可管理用户；审计日志仅系统管理员/审计员/安全管理员可查；教师不可审批建议；所有越权请求均被服务端拒绝。

### 7.2 数据汇聚与质量

**AC-DATA-01（Happy）**
- **Given** 一份不超过 5000 行、字段符合模板的岗位样本文件
- **When** 执行导入
- **Then** 导入在 10 秒内完成，任务状态为已完成，且成功/失败计数之和等于总行数。

**AC-DATA-02（Happy）**
- **Given** 一条已入库岗位样本
- **When** 查询其溯源信息
- **Then** 返回来源渠道、原始链接与采集时间，且与导入记录一致。

**AC-DATA-03（Happy + Sad）**
- **Given** 已存在唯一键相同的岗位样本
- **When** 再次导入同一文件
- **Then** 原记录被覆盖更新，岗位总数不增加；
- **And Given** 文件中存在缺必填字段的非法行
- **When** 导入完成
- **Then** 非法行计入失败数并给出失败原因，合法行正常入库。

**AC-DATA-04（Happy + Sad）**
- **Given** 一个启用状态、周期合法的采集任务
- **When** 到达触发时间或手动执行
- **Then** 任务执行并记录最近执行时间与结果，重复文件按唯一键增量覆盖；
- **And Given** 周期表达式非法
- **When** 保存或调度
- **Then** 任务被拒绝或停用，并给出明确原因。

**AC-DATA-05（Happy）**
- **Given** 已完成批量抽取的岗位数据
- **When** 查询质量报告与抽取进度
- **Then** 报告与进度的统计口径一致，且与岗位数据状态相符。

### 7.3 AI 能力

**AC-AI-01（Happy）**
- **Given** 一段包含技术要求的岗位描述
- **When** 执行 AI 抽取
- **Then** 返回技能、工具、工程能力三类标签，人工抽检准确率不低于 85%，并记录所用模型。

**AC-AI-02（Happy + Sad）**
- **Given** 选定区域存在足够历史岗位数据
- **When** 发起未来 3 个月需求预测
- **Then** 返回 3 个按月的需求值并标注模型与生成时间；
- **And Given** 选定区域无历史数据
- **When** 发起预测
- **Then** 系统明确提示数据不足，不返回编造的趋势。

**AC-AI-03（Happy）**
- **Given** 已建立语义索引的岗位数据
- **When** 输入自然语言描述并可选择区域
- **Then** 返回按语义相似度排序的岗位结果与命中总数，区域筛选生效。

**AC-AI-04（Happy）**
- **Given** 一条存在的岗位样本
- **When** 请求相似岗位
- **Then** 返回同族岗位且不包含自身。

**AC-AI-05（Sad）**
- **Given** 当前大模型不可用
- **When** 执行抽取
- **Then** 系统按规则回退本地规则词典完成基础抽取；若回退仍失败，则显式返回错误，不返回空结果冒充成功。

### 7.4 展示与报告

**AC-BIZ-01（Happy）**
- **Given** 已导入岗位数据
- **When** 打开数据看板
- **Then** KPI、趋势、薪资分布、技能词云、区域地图与排行均有数据展示，且数字与统计接口一致。

**AC-BIZ-03（Happy）**
- **Given** 存在当期统计数据
- **When** 导出年度报告
- **Then** 可成功下载 Word/PDF/Excel 文件，文件内容与当期统计一致。

**AC-BIZ-04（Sad）**
- **Given** 一个尚未完成的异步报告任务
- **When** 请求下载
- **Then** 拒绝下载并返回明确状态；任务完成后可正常下载。

### 7.5 课程资源与调整建议

**AC-CUR-01（Happy）**
- **Given** 课程库已维护课程、知识技能点与项目案例
- **When** 查看课程详情
- **Then** 返回课程基本信息、已绑定技能点与关联项目案例；课程编码保持唯一。

**AC-CUR-02（Happy）**
- **Given** 一个计划年度
- **When** 生成年度专业动态调整建议
- **Then** 建议覆盖专业方向、课程内容、技能新点三类，总数不少于 4 项，且每项均含数据依据。

**AC-CUR-03（Happy + Sad）**
- **Given** 教师提交一条调整建议
- **When** 专业负责人审批通过或驳回
- **Then** 状态从待审批变为已通过/已驳回，并记录审批人、时间与意见；
- **And Given** 该建议已处于终态
- **When** 再次审批
- **Then** 请求被拒绝，状态不变。

**AC-CUR-04（Sad）**
- **Given** 教师账号
- **When** 尝试审批建议
- **Then** 返回 403，且建议状态不变。

**AC-CUR-05（Happy）**
- **Given** 存在调整建议记录
- **When** 导出 Word/PDF
- **Then** 文件成功生成且内容与建议记录一致。

**AC-ADJ-01（Happy）**
- **Given** 数据服务可提供当期岗位与技能统计
- **When** 打开年度调整建议页或请求生成
- **Then** 按“方向 2 / 课程 4 / 技能新点 3”规则生成建议，指标来自真实统计，编号按年度与分类唯一，数量和分类计数与清单一致。

**AC-ADJ-02（Happy）**
- **Given** 某条建议已被采纳
- **When** 再次生成年度建议
- **Then** 该建议仍为已采纳，采纳人与采纳时间保持不变，其余建议按最新数据更新。

**AC-ADJ-03（Happy + Sad）**
- **Given** 专业负责人或系统管理员
- **When** 采纳一条待确认建议
- **Then** 状态变为已采纳并记录采纳人/时间，评审进度中的已采纳数量同步增加；
- **And Given** 教师或已采纳的建议
- **When** 再次采纳
- **Then** 越权返回 403、重复采纳返回 409，状态不变。

**AC-ADJ-04（Happy）**
- **Given** 尚未发生委员会评审与教务备案
- **When** 查看评审进度
- **Then** 仅“建议生成”为已完成；有采纳时“专业负责人复核”为进行中并显示真实采纳数，否则未发起；后两阶段均为未发起。

**AC-ADJ-05（Sad）**
- **Given** 数据服务不可用或未返回统计
- **When** 请求生成年度建议
- **Then** 返回 502 与明确错误信息，不生成、不保存任何建议。

### 7.6 大模型接入

**AC-LLM-01（Happy）**
- **Given** 系统管理员进入模型配置
- **When** 查询模型列表
- **Then** 返回模型名称、服务商、启用状态、是否当前与本年调用数，不返回 API Key 明文。

**AC-LLM-02（Happy + Sad）**
- **Given** 已存在一个当前模型
- **When** 将另一模型设为当前
- **Then** 原模型取消当前标记，新模型成为唯一当前模型；
- **And Given** 当前模型
- **When** 尝试删除或停用
- **Then** 请求被拒绝并提示先切换其他模型。

**AC-LLM-03（Happy）**
- **Given** 已配置当前模型
- **When** 执行抽取
- **Then** 调用当前模型并记录其模型名；调用失败时按 AC-AI-05 处理。

### 7.7 系统管理

**AC-SYS-01（Happy + Sad）**
- **Given** 系统管理员
- **When** 创建用户、启停账号或调整角色
- **Then** 变更生效并写入审计；
- **And Given** 非系统管理员
- **When** 执行上述操作
- **Then** 返回 403。

**AC-SYS-02（Happy + Sad）**
- **Given** 审计员或安全管理员
- **When** 查询审计日志
- **Then** 可按操作人、时间等条件分页查询；
- **And Given** 教师或数据分析员
- **When** 查询审计日志
- **Then** 返回 403。

**AC-SYS-03（Happy）**
- **Given** 发生导入、审批、采纳、模型切换或用户角色变更
- **When** 操作完成
- **Then** 审计日志中存在对应的操作人、动作、对象、结果与时间记录。

### 7.8 导航与访问

**AC-UI-01（Happy + Sad）**
- **Given** 已登录用户
- **When** 浏览分组导航
- **Then** 仅看到其角色允许的入口，页面标题与内容匹配；
- **And Given** 教师
- **When** 直接输入系统管理地址
- **Then** 跳转无权限页而非渲染管理内容。
